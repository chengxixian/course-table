## 管线改造（v2 之前，不含最终片）

### BGM 变成渲染参数

`Bgm` 现在接受 `file` / `volume`；`Main` 与 `Root` 透传 `bgmFile` / `bgmVolume`
（默认 `audio/bgm/bgm-final.wav` / `0.5`）。`bgm: false` 时**不挂任何 Audio**。
`staticFile()` 读取 `promo/remotion/public/`，所以 `bgmFile` 是相对该目录的 posix 路径。

### 渲染脚本

`promo/scripts/` 下三支 PowerShell（UTF-8 BOM，PS 5.1 可直接跑）：

| 脚本 | 参数 |
|---|---|
| `render-vertical-bgm.ps1` | `-BgmFile <rel> -Volume <0..1> -Out <mp4> [-Frames 0-599] [-Concurrency 4]` |
| `render-vertical-nobgm.ps1` | `-Out <mp4> [-Frames]` |
| `render-wide.ps1` | `-BgmFile <rel> -Volume <0..1> -Out <mp4> [-Frames]` |

共同行为：校验 BGM 存在且为 `.wav`（缺失即 throw，不回落默认值）；校验 0≤volume≤1；
props 以 **无 BOM JSON** 写盘（BOM 会让 Remotion 的 JSON.parse 失败）；
输出路径相对 `promo/`；`--log=info` 落盘并在结束时检查音频相关告警。

### 10 秒管线自检（非成片）

| 产物 | 时长 | 音轨 | 日志告警 |
|---|---|---|---|
| `promo/preview/selfcheck-vertical-bgm-10s.mp4` | 10.048s（600f@60fps） | 有 | 无 |
| `promo/preview/selfcheck-vertical-nobgm-10s.mp4` | 10.048s | 有（仅 SFX） | 无 |

两支尾部 1.2MB 音频负载 99% 字节不同 → 证明 `bgmFile`/`bgmVolume` 真的进了渲染，
且 `bgm=false` 路径确实只剩 SFX。缺失文件用例：`-BgmFile audio/bgm/does-not-exist.wav`
→ exit 1、报错明确、不产出文件。

**limiter 从 5.35 降到 2.71 dB**（竖/横），符合预期——混音峰值降了 1.2 dB，压缩器吃掉了更多，
限制器只需兜住最后一点。crest 15.06 刚好过 15.0 线（为达标把目标取 −16.1，仍在 [−16.2,−15.8] 内）。

无 BGM 版 limiter 反而是 5.65 dB：它没有音乐垫底，要凑到 −18 需要 **+12.2 dB** 增益，
峰值自然被限制器兜住。其 crest 29.46 dB 说明冲击相对主体仍然很突出，没有被压平。
