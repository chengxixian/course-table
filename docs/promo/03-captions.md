## 3. 事实边界（不做的宣称）

- `350 所学校`：`assets/schools.json` 里恰好 350 条，写"350 所"成立；不写"全国高校全覆盖"。
- `AI 兜底`：源码里的确切措辞是"把课表文字粘贴到这里，AI 会负责识别"，因此只写
  "网页 AI 兜底"，**不写**"AI 全自动解析任何教务系统"。
- `7 种格式`：WakeUp / ICS / CSV / Excel / PDF / 文本 / 手动，与 `import_file_screen.dart` 一一对应；
  PDF 限定为"文本型 PDF"（源码注释：扫描图片版无法提取）。
- 不写"永久免费""无广告"等未在源码/README 中确认的承诺（README 只声明 GPL-3.0 开源）。
- 不出现真实姓名、学号、真实课程表；`42 个事件` 是演示数字（虚构示例课表的总节次数）。
