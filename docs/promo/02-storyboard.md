## 转场

全部硬切 + 元素层运动。全片**无整画面级冲击**（aesthetic-rules R4 计数 = 0），无逐拍抖动。
S7 的整屏色变属于「元素层色彩迁移」，不计入 slam。

## 页面状态来源（D3 说明）

本片没有可运行的 App 实例（本机无 Flutter SDK / adb / 模拟器），因此手机内画面是
按 `lib/` 源码**逐值复刻**的合成 UI，不是真实截图：

- `lib/ui/week_screen.dart`：`dayWidth 88 · timeWidth 48 · rowHeight 56 · breakHeight 4`、
  日头 48 高、今日日期 22px 圆形高亮、左侧 3px 色条课程块、拖拽落点 `#4285F4` 2px 描边
- `lib/ui/components.dart`：`CoursePalette._light` 8 组色值、`PageHeader` 22×2 短横 + 9px/1.5 kicker、
  `WeekHero` 5×44 竖条、课程详情弹层的全部字段与按钮
- `lib/ui_theme.dart`：M3 角色色（seed `#0B57D0`）、圆角 12/16/22/24/26/28、字体族
- `pubspec.yaml`：`FangSongCN → FandolFang-Regular.otf`、`TimesNewRoman → LiberationSerif-Regular.ttf`
  （两个字体文件直接取自仓库 `assets/fonts_ofl/`，与 App 同源）


## 60fps 与动效增强（task-3）

交付帧率 60fps（2400f）。镜头代码仍以 30fps「作者帧」编写，`Main.tsx` 里
`local = useCurrentFrame() / FS`（FS=2）把每条曲线采样两次——时值不变、时间分辨率翻倍。

| 镜头 | 新增动效（在原有唯一主动作之上） |
|---|---|
| S1 | 数字用 `clip-path` 自下而上压印显现；running head 逐字打字；数字下方基线尺绘制 |
| S2 | 背景栅格视差（慢于手机）；手机 1.000→1.014 缓推；一条被圆角裁切的扫描线扫过课块区 |
| S3 | 弹层用阻尼弹簧收口（0.5→约 1.03 过冲→1.0），替换原来的两段线性缩放 |
| S4 | 卡片从左下带 −1.3°…+0.7° 旋转「flock」入列；「350 所高校」数字 0→350 计数 |
| S5 | 两枚滞后残影（lag 0.22 / 0.42）跟随被拖课块；落点格呼吸脉冲（scale±1.4%） |
| S6 | 四张卡改用 `easeLand`（y1=1.32）自上方轻微过冲落位，形成 cascade |
| S7 | 色彩 morph 分角色延迟：surface 先洗、容器跟随、primary 最后落（`mixRolesStaggered`） |

约束复核：
- 整画面/相机层冲击（slam）：**0 处**（全部是元素层运动；S2 扫描线是裁切在卡片内的低透明度扫掠，不是 slam）
- 品牌字标 hold：S1 第 140–300 帧（约 2.7s）、S7 第 2280–2400 帧（1.2s），均 ≥1s
- 事实文案未变：四种小组件 / 无 Windows / GPL-3.0 / 350 所 / 7 种格式
