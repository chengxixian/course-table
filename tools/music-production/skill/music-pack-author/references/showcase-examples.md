# Showcase Examples

Every extension pack requires at least one canonical showcase.

## README structure

```markdown
# <Example Name>

**<Pack / production type>**

<One-paragraph description.>

## Prompt

```text
Use music-compose, music-produce and music-evaluate with the <pack-name> extension pack.

<Full production brief>
```

## What this showcases

<Explain which distinctive pack behaviours the example exercises.>
```

## Prompt quality

A strong showcase prompt includes:

- production purpose;
- format/use context;
- musical constraints;
- workflow expectations;
- preservation requirements;
- delivery requirements;
- evaluation priorities.

Do not make the example merely "make a <genre> song".

Do not invent a `What happened` section until the production has actually run and evidence exists.
