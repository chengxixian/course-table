# Evaluation Lifecycle

Evaluation intensity follows the artifact's purpose and workflow state.

## Draft

Ask only whether the draft can support the decision it was created to test. Ignore final-stage polish that is irrelevant at this resolution.

## Refine

Verify the requested change first, then preservation, edit boundaries/regressions, and previous approvals.

## Final

Run all applicable creative, production, technical and delivery checks.

A required check that cannot run is BLOCKED or NOT RUN, never PASS.
