# Reference Analysis

References are inputs. The persistent production artifact is the analysis of what should transfer from them.

Capture only characteristics relevant to the current work, for example:

- groove;
- instrumentation;
- harmonic language;
- structure;
- energy progression;
- vocal treatment;
- production aesthetic.

Avoid vague instructions such as “make it sound like artist X”. State transferable musical/production properties instead.

Reference analysis should be concise enough to constrain later decisions without turning into an automated musicology report.
