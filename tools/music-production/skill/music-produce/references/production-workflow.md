# Production Workflow

Normal production path:

```text
approved composition + arrangement
→ demo
→ production review
→ final production
→ technical QC
→ evaluation
→ delivery
```

The demo is the main integration draft. If the demo reveals a composition or arrangement problem, return upstream rather than hiding it with more expensive production.

Full production should still be incremental. A representative verse/chorus prototype may be enough to prove production language before rendering the whole piece.
