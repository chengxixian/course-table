# Delivery

A delivery package identifies which approved outputs constitute the handoff.

Possible contents:

```text
approved mix/master
instrumental or alternate version when requested
genuine stems when available
timing metadata
credits/metadata
delivery manifest
```

A music `master` is not a video `video_master`.

Do not call source-separated approximations “native stems”. Label them as separated estimates if an optional separation workflow is used.

Use FFmpeg/ffprobe for deterministic format validation, not for pretending technical normalisation is a complete creative mastering workflow.
