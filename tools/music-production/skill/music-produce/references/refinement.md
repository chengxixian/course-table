# Refinement

Refinement begins with diagnosis.

```text
identify defect
→ identify owning decision/stage
→ identify smallest affected region
→ choose a compatible edit path
→ apply change
→ verify preservation and boundaries
```

Prefer local inpainting, continuation, reference-conditioned editing, section replacement or deterministic assembly when appropriate.

Whole-track regeneration is a fallback, not the default.

If local editing is unsupported, rediscover Replicate candidates before introducing an external provider.
